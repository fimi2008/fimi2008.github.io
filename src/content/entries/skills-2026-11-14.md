## Codex 安装

命令按榜单顺序排列。在目标项目根目录按需执行一行，末尾加 `-g` 可跨项目使用。

```bash
npx skills add designed-by-ai/skills --skill design-mobile-apps -a codex
npx skills add vercel-labs/skills --skill find-skills -a codex
npx skills add vercel-labs/agent-browser --skill agent-browser -a codex
npx skills add heygen-com/hyperframes --skill hyperframes -a codex
npx skills add flowkit-labs/skills --skill website-builder -a codex
npx skills add heygen-com/hyperframes --skill media-use -a codex
npx skills add gencraft-labs/skills --skill ai-music -a codex
npx skills add heygen-com/hyperframes --skill hyperframes-cli -a codex
npx skills add gencraft-labs/skills --skill image-to-video -a codex
npx skills add gencraft-labs/skills --skill video-edit -a codex
```

## 值得试一个

打开一个小程序项目，给 `find-skills` 一个具体任务，例如「从现有页面提取一套可复用的按钮和表单样式」。看看它能否给出明确的候选、来源和所需环境，先选一项在副本里试。
